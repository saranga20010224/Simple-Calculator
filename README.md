# Simple-Calculator
A command-line calculator in Python supporting addition, subtraction, multiplication, division, power, and remainder operations.

🧮 Simple Python Calculator
A lightweight command-line calculator built in Python that supports basic arithmetic operations. Designed for beginners to understand functions, loops, and input handling in Python.
Features

Supports +, -, *, /, ^ (power), and % (remainder)
Input validation with helpful error messages
# to terminate and $ to reset the session
Handles division errors gracefully
